Como funciona

  1. Permita a câmera. O site pede acesso para mostrar a imagem ao vivo.
  2. Marque os cantos do chão de cada cômodo, seguindo as paredes. As linhas aparecem sobre a imagem para confirmar o que já foi escaneado.
  3. Aponte para o teto para medir o pé-direito (ou pule).
  4. Veja a planta 2D e 3D, renomeie os cômodos e ajuste medidas.
